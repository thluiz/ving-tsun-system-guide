:::note[Estrutura planejada]
- O termo "sistema": vago em português, preciso no uso chinês — definição, tradução, ideograma
- Hai Tong (系統) como "reunião de fios"
- O pensamento chinês como relacional: não os elementos, o espaço entre eles
- A tradição chinesa de codificação por listas (dinastia Tang)
- Lista ≠ inventário: é instrumento de variação
- "Não há pior perigo do que imobilizar-se num caso dado"
- A lista em que a ordem altera o produto — o oposto da receita de bolo
- Como ler uma lista: Sam Faat e a ordem interna invisível
- Integridade: os elementos que definem a identidade de um sistema
- Sistema aberto e sistema fechado
- Sistema, estilo e método: Kuen / Kuen-Fa / Kuen-Sung
:::

> *"Kung Fu sem sistema não é Kung Fu. Kung Fu que depende de sistema, não é bom Kung Fu."*
>
> ~ Grão-Mestre Moy Yat

Se Kung Fu não tem tradução exata para o português ou para o inglês, sistema também é um termo vago. Quase qualquer coisa que tenha várias partes pode ser chamada de sistema.

No outro lado do mundo, a China, devido às suas convulsões internas, teve sempre um terreno mais instável, porém sem rupturas bruscas de suas tradições de pensamento. Apoiar-se nas variáveis era a forma mais eficiente de transitar em um cenário em constante evolução. O pensamento chinês nasce sistêmico por natureza, não se valoriza as partes em detrimento do todo. É curioso como isso perpassa até as estruturas familiares: o nome da família vem antes do indivíduo.

## *Encontros de Mestrado*

<Aside type="caution" title="II Encontro (13/03/2026)">
1. Etimologia: "sistema" no grego = "aquilo que se mantém junto"; em chinês hai tong = "reunião de fios"
2. Sistema como input-processamento-output vs sistema chinês como lista/receita (ordem altera o produto)
3. Sistema é artificial (positivo) — nenhum gesto do VT é natural, tudo foi desenhado
4. Natureza não se prescreve, emerge — não dizer "a natureza do SND é X", deixar brotar
5. "O sistema é mudo" — qualquer interpretação é do praticante, não do sistema
6. Sistema como partitura / maestro — partitura fixa, artista na interpretação
7. Começar dentro do sistema, eventualmente descolar — permissão pessoal
8. Integridade: 6 elementos, nem mais nem menos — adicionar ou remover muda a identidade
9. Sistema aberto vs fechado — núcleo fechado (6 domínios), interpretação aberta
10. Interdependência, não independência — entrar num sistema já o afeta
11. Fita de Moebius — sistema que retorna a si, dentro vira fora
12. Elementos não-lineares e retroativos — Biu Ji muda como você vê o Siu Nim Tao
13. Sistema vs estilo vs método — Kuen/Kuen-Fa = sistema, Kuen-Sung = estilo
14. Sistema de Kung Fu como lista onde ordem importa
15. Pré-requisitos amplos = sistema mais eficaz — minimizar barreiras de entrada
</Aside>

<Aside type="caution" title="III Encontro (17/04/2026)">
16. Kung Fu (subjetivo) vs Sistema (objetivo) — Si Fu: sistema é aspecto objetivo, quase material (S5)
17. "O sistema é mudo" / "definir é limitar" — praticante interpreta, sistema não prescreve (S11)
18. Sem sistema, Kung Fu para de evoluir — armadilha do autoaprisionamento (S12)
</Aside>

<Aside type="caution" title="IV Encontro (03/07/2026)">
19. Hai Tong é lista onde a ordem é essencial — uma receita de bolo é lista em que a ordem dos ingredientes não importa; o Hai Tong é o oposto, trocar a ordem muda o sistema
</Aside>
